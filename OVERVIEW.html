Architecture
🔄
RAG Pipeline
1
Document Ingest
PDF · DOCX · TXT · MD · URL → recursive character chunking (chunk=512, overlap=64)
↓
2
Embedding
Batch 32 · Float32Array blob (SQLite) or vector column (pgvector)
↓
3
Hybrid Retrieval
Cosine vector search + BM25 (k1=1.5, b=0.75) → RRF (w=0.7/0.3)
↓
4
SSE Stream
Citations first → token stream → done event with latency ms
